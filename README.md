# 📊Анализ маркетинговой кампании спортивного магазина

## 🎯Цель проекта
Оценка эффективности маркетинговой кампании, сегментация клиентов и прогнозирование склонности к покупке обуви.

## 📝Задачи
- Провести A/B-тестирование влияния персонализированных скидок на ключевые метрики.
- Выполнить кластеризацию клиентов для персонализации маркетинговых стратегий.
- Построить ML-модель для прогнозирования склонности к покупке обуви.

## 🛠️Используемые методы и инструменты
- **A/B-тестирование**: χ²-тест, z-тест, Shapiro-Wilk, Mann-Whitney
- **Кластеризация**: K-Prototypes (совместная обработка категориальных и численных признаков)
- **ML-модель**: LightGBM (классификация + регрессия)
- **Языки и библиотеки**: Python, pandas, scikit-learn, LightGBM, kmodes, seaborn, matplotlib, SQLite

## 📈 Результаты
- Рост выручки на клиента на **19.4%**
- Увеличение частоты покупок на **25.6%**
- Снижение конверсии на **3.67%**
- Снижение среднего чека на **5.0%**

- Выделено **5 кластеров** клиентов с различными паттернами поведения
- Качество ML-модели:
    - ROC-AUC: **0.7744**
    - F1-macro: **0.7026**
    - R² по регрессии: **0.4419**
